# In1_5 与 TAB 集成：实现细节确认清单

依据：工作区 `In1_5.md`、用户提供的 TAB 论文（重点为第 4 节及第 5.1.2 节）、本地 TAB 代码及数据元信息。

方案的目标变换、预测依赖和评分流程已足够定义完整模型。尚需明确的是数据使用口径、具体网络配置、训练选模规则和评价接入方式。下文将方案已有规定与建议补充值分开列出；所有建议值均为实现起点，尚无实验结果支持其最优性。

## 1. 方案已明确的部分

以下内容可以直接作为实现约束，无须重新选择：

- 正常数据按时间先分为 80% 训练和 20% 验证，再分别构造窗口；测试窗口也完整位于测试集合内。标准化和目标参考统计只使用训练部分。
- 默认 `L=128`，邻域块长为 `{4,8,16,32,64,128}`，自身统计跨度为 `{16,32}`。支持 `L=64/128/256`，尺度随 L 成比例变化。
- 邻域路径对每个变量输出 12 个水平与变化坐标；自身路径输出 6 个统计坐标和 1 个末点值。两条路径参数独立。
- 邻域预测完全排除目标变量的观测；自身统计预测完整排除目标片段；末点预测不读取当前点。
- 去趋势、A/C/J 的定义、能量下限和正常能量范围均按原公式实现。近常量统计坐标固定输出训练均值，仍计入损失和评分。
- 使用全部非自环来源，进行一次邻域汇总。反集中项采用 Top-r 权重总量；`d=2` 时该正则为零。
- 默认 `chi=0.25`、`alpha=0.5`、`beta=1`，误差尺度使用正常验证平方残差的 95% 分位数，阈值使用验证整体分数的 99% 分位数；报警条件为严格大于阈值。
- 固定网络后依次确定支持标志、误差尺度和阈值。测试时只更新窗口，不更新参数或参考统计；不使用测试标签选配置，不执行 point adjustment。

这些约束能防止当次目标复制，但不能保证持续异常不会被后续历史吸收。反集中正则约束的是混合权重分配，完整输入抗扰性仍需实验评价。

## 3. 需要确认的实现选择

### D1. 数据集与独立实体

**请明确：首批数据集、使用本地 TAB 版本还是其他官方版本，以及一个文件是否代表一个独立实体。**

本地存在 `SWAT.csv`、`SMD.csv`、`SMAP.csv`、`MSL.csv`、`PSM.csv`。SWAT 元数据给出训练段 495,000 点、测试段 449,919 点；按方案得到训练 396,000 点、验证 99,000 点。

建议首先接通本地 SWAT，同时支持按文件列表运行其他确认适用的数据。每个独立实体单独训练、单独估计统计量并校准阈值。部分文件若拼接了多个实体，需提供边界或改用逐实体文件；现有元数据仅提供整条序列的训练边界，不能保证实体之间不会跨窗。

正常训练条件需要由数据版本保证。实现中可用训练标签检查纯度；若出现异常标签，建议报错并定位，不能删除异常行后把两侧数据重新拼成连续序列。该检查不用于监督学习或选模。

实际采样间隔需要原始数据说明或明确配置。SWAT 文件的 `date` 样例为整数序号，不能据其经 `pd.to_datetime` 转换后的间隔推断物理时间。

### D2. 输入列、标准化与缺失值

**请明确：是否保留离散控制量、常量通道；缺失值如何处理；是否重采样或裁去启动段。**

建议默认：

- 使用已准备数据的全部数值特征列，排除标签和时间列，保留离散及常量通道；固定列顺序。
- 不额外重采样、平滑或裁切。确需裁切时，将规则和时间边界写入数据配置。
- 按变量使用训练部分的均值和总体标准差（`ddof=0`）；标准差不大于 `1e-8` 时缩放因子取 1，并记录这些通道。
- 对缺失值或无穷值默认报错。若选择因果前向填补，则在每个集合内部处理，开头无历史时用训练均值，并记录填补位置；冻结实验应区分填补平段和真实冻结。

逐窗口标准化会改变能量目标，跨变量或跨时间归一化还可能破坏输入排除约束，不能直接套用到本方法。

### D3. 冷启动、有效评价时段与异常边界

**请明确：采用独立测试窗口的冷启动口径，以及如何处理与评价边界相交的异常事件。**

建议严格遵循原方案：长度 T 的测试段输出与原时间轴等长的结果，前 `L-1` 点标为无有效分数，通过显式有效掩码排除；其余每个点使用截至当前点的完整窗口。`L=128` 时排除前 127 点，保留全部测试尾部。

- 逐点 Precision/Recall/F1、AP、正常时段误报率均在有效时段计算，不将无预测位置补成正常预测。
- ADD 从原始标签提取事件，只统计完整落在有效时段内的事件；不把被裁断的事件当作新事件。记录被排除事件数。测试末端事件是否完整，也需按原始边界信息判断。
- 被裁断事件落入有效时段的点仍参与逐点指标。
- 比较不同方法或 `L=64/128/256` 时，使用共同有效时段。例如三种窗口联合比较时，起点统一到至少第 256 个测试点。
- 训练、验证或测试不足以构成完整窗口时明确报错，不自动缩短 L。

如果要用训练或验证尾部给测试提供历史，需要明确修改原方案“各集合独立构窗”的规定。

### D4. 评价入口与外部基线协议

**请明确：是否采用专用评价策略；本次是否同时统一所选基线的阈值与有效时段。**

建议新增可选的因果检测评价策略：一次训练和校准后，以同一模型生成连续分数及固定阈值报警，按有效掩码分别评价，记录阈值与有效区间。复用 TAB 的模型加载、数据切分和结果记录接口。

主指标建议显式配置为 `precision/recall/f_score/auc_pr/add/fpr`，其中 `fpr=FP/(FP+TN)` 需新增；另存每个真实事件的检出状态和延迟。`adjust_*`、测试标签选出的最佳 F1、阈值扫描最好结果不进入主指标。阈值敏感性作为单独实验，保留每个候选值的完整结果。

若本次包含外部基线对比，需要明确基线名单，并检查其是否满足正常训练、验证校准和时间依赖要求。依赖未来上下文的方法应记录实际可用时刻及延迟。

### D5. TCN 与共享网络结构

**请明确：以下结构建议是否可作为完整主模型的默认配置。**

| 项目 | 建议补充值 |
|---|---|
| 邻域与自身隐层宽度 | `p_N=p_S=32` |
| 上下文与消息宽度 | 均为 32 |
| 变量、尺度、统计跨度嵌入 | 维度均为 8；邻域变量标识在目标/来源角色间共用一张表；自身嵌入独立 |
| 嵌入注入 | 与每个位置的输入拼接，再线性投影到 TCN 宽度 |
| TCN 残差块 | 每块两次核长 3 的左因果卷积，膨胀率按 `1,2,4,...` 增长 |
| 邻域 TCN | 4 个残差块，感受野 `1+4*(1+2+4+8)=61`，覆盖最多 32 个粗时间块 |
| 自身 TCN | 按 L 自动选择最少块数，使感受野覆盖 `L-1`；`L=128` 时 6 块，感受野 253 |
| 激活与归一化 | GELU；每个时间位置仅沿隐特征维度做 LayerNorm |
| Dropout | 0.1，仅训练启用 |
| U、尺度门控、V、关系生成器、邻域解码器、统计头、末点头 | 分别使用独立的两层 MLP，隐藏宽度 64，各模块内部按方案共享参数 |
| 温度 | `T_sc=T_rel=1`，固定，不学习 |

所有目标共享来源编码，但目标 i 的上下文、路由及解码均不能读取来源 i 的观测。归一化不能跨变量或跨时间汇总当前输入。自身 TCN 的统计头读出位置必须保留严格前缀依赖。

以输入 `[x_(t-L+1),...,x_(t-1)]` 的零基索引计，统计头读 `L-h-1`，末点头读 `L-2`。`L=128` 时，h=16/32 分别读索引 111/95，末点读 126。

### D6. 损失系数、数值规则与训练选模

**请明确：采用固定初始配置，还是实现自动超参数搜索；自动搜索时需给出可执行的选择规则。**

| 项目 | 建议补充值 |
|---|---|
| 路径损失系数 | `lambda_N=lambda_S=1` |
| 反集中正则系数 | `lambda_A=0.1`，作为待验证起点 |
| 邻域支持参数 | `eta_g=0.05`，`epsilon_g=1e-8` |
| 方差和评分尺度下限 | `epsilon_v=1e-6`，`epsilon_q=1e-6` |
| 优化器 | AdamW，学习率 `1e-3`，weight decay `1e-4` |
| 最大训练轮数 | 50 |
| 早停 | patience=7，min_delta=`1e-4`；监控验证 `lambda_N*L_N+lambda_S*L_S`，不计正则项；恢复最佳检查点 |
| 梯度裁剪 | 全局范数 1 |
| 学习率调度 | 默认不使用 |
| 构窗与批次 | 训练、验证、校准、测试均 stride=1；仅训练打乱窗口顺序；全部阶段保留最后不足批次的数据 |

原文“兼顾正常拟合与权重集中度”尚不是唯一可执行的自动选择规则。建议主配置先固定正则系数，另以 `{0,0.01,0.1,1}` 记录验证重构误差和集中度诊断；若自动选择，需要明确允许的拟合损失增幅、集中度要求及并列规则，不能用测试 F1 决定。

统计计算建议统一为：粗指标和统计坐标的均值、总体方差、分位数按训练有效窗口端点等权估计；末点方差按训练观测点估计；分位数使用线性插值。能量下限先由 V 的训练分布确定，再计算 A 的均值、方差和范围。

参考统计与分位数计算使用 float64，网络默认 float32，默认关闭混合精度。校准使用完整正常验证窗口；允许分块或磁盘暂存以控制内存，不默默改为随机子集。统计头范围退化或坐标近常量时按原文固定输出规则处理。

### D7. 本次“完整实现”的交付范围

**请在以下范围中选择；A 已包含完整主方法，不删减主模型模块。**

| 选项 | 交付范围 |
|---|---|
| A | 完整主方法、TAB 注册与专用评价、配置、服务器启动脚本、保存/加载、必要验证 |
| B | A，加第 6.2 节全部消融和第 6.3 节可控扰动工具 |
| C | B，加指定外部基线在统一协议下的适配；需明确基线名单和实现版本 |

若选择 B/C，还需固定以下会改变对照含义的规则：

- 静态尺度与静态图：建议使用训练后固定、与窗口无关的可学习权重；均匀权重作为另外的简单参考，不与“静态”混用。
- 统计量子集：建议对保留坐标重新等权归一化，维持统计部分总权重 `1-chi`。
- 邻域单路：建议所有变量均使用邻域分数，不按 `b_i=0` 回退自身路径；否则不再是单路对照。
- 自身机制对照：复用并冻结同一个邻域检查点；各自身变体独立训练，并重新校准 q 和阈值。不能只保证随机种子相同而分别重训邻域。
- 逐点去趋势尾段对照：需要确定每个跨度的输出头，以及先在跨度内逐点平均、再跨跨度等权的损失和评分规则；逐点误差尺度也需重新校准。
- 固定均值和前一非重叠片段参考：需明确是否同样施加能量预测范围约束。建议保持范围约束一致，以单独检验历史条件网络的作用。
- 目标片段可见消融：建议仅解除统计头的片段排除，末点头继续读 t-1，避免同时改变两个机制。
- 合成扰动：需指定未用于训练、选模和校准的正常数据来源、扰动强度及持续长度。建议预先固定网格，以物理幅度或训练标准差为单位，不根据检测结果挑选。

### D8. 随机种子、结果统计与保存内容

**请明确：随机种子数量，跨实体汇总口径，以及是否保存全部路由权重。**

建议默认使用 `[42,43,44,45,46]`。每个种子保留独立结果；多实体数据先在每个种子内对实体指标等权平均，再报告种子间均值和样本标准差。事件合并后的 ADD 可另报，但需与实体等权平均明确区分。

保存模型参数、列顺序、标准化参数、全部参考统计、近常量掩码、支持标志、误差尺度、阈值、配置和种子。逐点输出保存时间索引、有效掩码、整体分数、报警及必要的变量分数；测试标签只由评价侧读取。另存事件表和集中度诊断摘要。

默认不保存所有窗口的完整 `pi/A/v` 张量，可按固定样本或指定事件导出。无定义指标和失败运行保留 NaN 与原因，并报告有效数量，不以其他运行的均值填补。

### D9. 服务器约束与推理形式

**请明确：服务器系统、单卡显存和可用内存；是否除 TAB 批量评价外，还需要逐点流式接口。**

建议默认单卡运行，batch size=32，CPU 支持小规模验证；数据集/种子任务按需调度。保留完整的 `O(d^2 K)` 路由，显存不足时采用等价分块与必要的梯度重计算，不自动减少邻居或候选尺度。

TAB 中批量处理因果窗口可以保持逐点因果性；实际流式接口还需维护窗口缓冲区、冷启动状态及实体重置规则。两种推理形式的有效分数应一致。

## 4. 确认后的集成位置与验证范围

代码暂用名 `DynamicNeighborhoodStat`，可在实现前指定其他名称。

必要验证限定为改变的关键路径：

1. 目标公式与张量形状；常数/线性片段的去趋势结果，以及 `d=2` 的正则边界。
2. 固定模型下扰动目标自身，邻域预测不变；扰动目标片段，统计预测不变；扰动当前点，末点预测不变。结合梯度和数值扰动核查。
3. 小规模合成序列完成训练、顺序校准、保存/加载和 TAB 评价，检查前缀无效区、最后一批和事件延迟对齐。
